# 📊 Pandas Sales Analysis

A practical **Pandas data analysis project** using the Superstore dataset.  
This project focuses on analyzing sales, profit, customers, products, regions, and other business metrics using Python and Pandas.

---

## 📌 Project Overview

The purpose of this project is to practice and demonstrate practical **Pandas data analysis skills** by working with a real-world sales dataset.

The analysis includes data cleaning, filtering, grouping, aggregation, feature creation, customer analysis, sales analysis, and business performance analysis.

---

## 🗂️ Dataset

The project uses the **Superstore dataset**, which contains information about:

- Orders
- Customers
- Products
- Categories
- Regions
- Sales
- Profit
- Quantity
- Discounts
- Dates
